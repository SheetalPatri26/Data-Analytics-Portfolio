# Dataset Information

## Source
Divvy Historical Trip Data

## Dataset Period
October 2025 – September 2026

## Dataset Description
The dataset contains historical bike-share trip records, including information about ride IDs, bike types, start and end times, and rider membership types.

## Data Preparation
- Combined 12 monthly datasets.
- Cleaned and prepared the data using Power Query.
- Removed rides exceeding the selected ride-duration limit.
- Prepared the dataset for analysis in Excel and Power BI.

## Data Availability
The original datasets are publicly available from the Divvy trip data source.

Source: https://divvy-tripdata.s3.amazonaws.com/index.html

Note: The original CSV files are not included in this repository because of their large size.
